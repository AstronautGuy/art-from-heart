# Requirements

## Scope

### Phase 1 Priority
- Comprehensive Admin Dashboard for category/product CRUD
- WhatsApp checkout cart processing
- Settings config for shipping models & free shipping threshold toggle
- Frontend Store (Home, Shop, Product, About, Contact)
- Cloudflare R2 bucket integration for image uploads
- Clerk Auth for Customers & Admin

### Out of Scope (Currently)
- Active payment gateway processing (Focusing exclusively on WhatsApp checkout for Phase 1).

## Acceptance Criteria
- Admin must be able to change all fundamental product and pricing elements without developer intervention.
- The UI MUST align with the specified aesthetic (pastel, soft, micro-animated).
