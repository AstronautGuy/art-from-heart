# Tech Stack

The project uses a modern T3-style stack configuration:

## Core
- **Framework**: Next.js 15.x (App Router)
- **UI Library**: React 19 / React DOM 19
- **Language**: TypeScript

## Styling
- **CSS Framework**: Tailwind CSS v4 (with PostCSS)
- **Plugin**: prettier-plugin-tailwindcss

## Data & Backend
- **Database ORM**: Drizzle ORM
- **Database Driver**: Postgres
- **API Setup**: tRPC (Server & Client)
- **Data Fetching**: React Query (TanStack Query v5)

## Tooling
- **Linting**: ESLint (Next.js config)
- **Formatting**: Prettier
- **Environment Variables**: @t3-oss/env-nextjs
