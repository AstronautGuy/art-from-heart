# Integrations

## Authentication
- **Clerk** (`@clerk/nextjs`): Handles user authentication, registration, and session management.

## Database
- **PostgreSQL**: Used as the primary relational database. Integrated directly via the `postgres` package and queried using `drizzle-orm`.

## API Layer
- **tRPC**: Provides end-to-end typesafe APIs between the Next.js frontend (client and server components) and the Node backend.
