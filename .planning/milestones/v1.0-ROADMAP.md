# Roadmap

## 🟢 Phase 1: Database & Core Infrastructure
**Goal:** Implement the Postgres database tables (categories, products, settings), configure the Clerk auth middleware for the admin role, and set up Cloudflare R2 image upload utilities.
**Canonical refs:**
- .planning/PROJECT.md

## 🟢 Phase 2: Admin Dashboard
**Goal:** Build the protected admin dashboard to perform CRUD operations on products, categories, shipping rules, featured items, and banners.

## 🟢 Phase 3: Product Storefront
**Goal:** Implement the user-facing store pages (Home, Shop, Product Detail, About, Contact) applying the pastel visual theme and micro-interactions.

## 🟢 Phase 4: WhatsApp Cart Checkout
**Goal:** Implement robust client-side cart state management and handle the "checkout loop" script that constructs and redirects to the pre-filled WhatsApp message API.
